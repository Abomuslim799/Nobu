# 3rd + mixed conditionals
meta: Murphy EGU 40 + AGU · B2 → C1

## 🟢 Asos
**3-shart** — o'tmishdagi xayoliy holat (bo'lmagan narsa):
**if + had V3, would have V3**
EN: If I **had left** earlier, I **wouldn't have missed** the bus. || ketmadim, ulgurmadim

## 🟡 O'rta
**Aralash (mixed)** — o'tmish sabab → hozirgi natija:
**if + had V3, would + V1**
EN: If I **had studied** medicine, I **would be** a doctor now.
Teskarisi — hozirgi holat → o'tmish natija:
**if + past, would have V3**
EN: If I **were** braver, I **would have asked** her out.

| Sabab | Natija | Tuzilma |
|---|---|---|
| o'tmish | o'tmish | had V3 → would have V3 |
| o'tmish | hozir | had V3 → would V1 |
| hozir (doimiy) | o'tmish | past → would have V3 |

## 🔴 Advanced
- Inversiya (if'siz): **Had** I **known**, I would have come.
- **could have / might have** would o'rniga: If we'd trained harder, we **could have** won.
- **If it hadn't been for / But for** + ot: **If it hadn't been for** your help, I'd have failed.

## ⚡ Hiylalar
- Har qismni alohida so'rang: **qachon?** O'tmish → had/have V3; hozir → past/would V1.
- Gapirishda qisqartmalar: If I'**d known**, I'**d have** come — ikkita 'd turli: had va would.

## ❌ Tipik xatolar
- ~~If I would have known~~ → If I **had known**
- ~~I would helped~~ → I would **have helped**
- ~~If I had studied, I would have been a doctor now~~ (hozir) → I **would be** a doctor now

## ✅ O'zingni tekshir
- "Agar bilganimda, aytgan bo'lardim" → If I **had known**, I **would have told** you.
- "Tibbiyotni o'qiganimda, hozir shifokor bo'lardim" → If I **had studied** medicine, I **would be** a doctor now.
