# Conditionals 0–2
meta: Murphy EGU 38–39 · A2 → B2

## 🟢 Asos
| Tur | Tuzilma | Ma'no | Misol |
|---|---|---|---|
| 0 | if + present, present | har doim to'g'ri, fakt | If you heat ice, it **melts**. |
| 1 | if + present, **will** + V1 | real kelajak | If it **rains**, I'**ll stay** home. |
| 2 | if + past, **would** + V1 | xayoliy hozir/kelajak | If I **had** money, I'**d travel**. |

> 💡 if qismi oldin yoki keyin turishi mumkin. Oldin tursa — vergul: If it rains, … / … if it rains.

## 🟡 O'rta
- **If I were you…** — maslahat (was ham gapirishda uchraydi, lekin were — standart).
- **unless** = if… not: **Unless** you hurry, you'll be late.
- **as long as / provided that** — faqat shu shartda: You can go **as long as** you're back by 10.
- **in case** — ehtiyot uchun (shart emas): Take an umbrella **in case** it rains.
- 1-shartda **will** o'rniga: may/might/can/imperative: If you see him, **tell** him.

## 🔴 Advanced
- **Should** bilan inversiya (rasmiy 1-shart): **Should** you need help, call us.
- **Were** bilan inversiya (2-shart): **Were** I in your position, I'd refuse.
- **If it weren't for / But for** — If it weren't for you, I'd be lost.
- **Supposing / Imagine / What if** + past: **What if** we **lost**?

## ⚡ Hiylalar
- Real imkonmi (bo'lishi mumkin) → 1-shart. Xayolmi (hozir bunday emas) → 2-shart.
- **if** qismida hech qachon **will/would** yo'q (muloyimlik "if you would…" dan tashqari).
- 2-shartda past — vaqt emas, "**xayoliylik**" belgisi.

## ❌ Tipik xatolar
- ~~If it will rain~~ → If it **rains**
- ~~If I would have money~~ → If I **had** money
- ~~If I was you~~ (rasmiyda) → If I **were** you

## ✅ O'zingni tekshir
- "Agar pulim bo'lganda, sayohat qilardim" → If I **had** money, I **would travel**.
- "Shoshilmasang, kechikasan" → **Unless** you hurry, you'll be late.
