# Talaffuz: so'zlarni bog'lash (linking)
meta: Payshanba · 5 daq

## 🟢 Asos
Ingliz tilida so'zlar alohida aytilmaydi — **bir-biriga ulanadi**.
| Qoida | Misol | Eshitiladi |
|---|---|---|
| undosh + unli | turn **o**ff | tur-noff |
| | pick **i**t up | pi-ki-tup |
| bir xil undosh | bla**ck c**at | blakat |

## 🟡 O'rta
Unli + unli orasiga kichik tovush qo'shiladi:
- /w/: **do it** → do-wit, **go out** → go-wout
- /j/: **I am** → I-yam, **the end** → the-yend
- /r/: **far away** → fa-raway (British)

## 🔴 Advanced
- Assimilyatsiya: **did you** → /dɪdʒuː/ ("dijyu"), **got you** → "gotcha", **want you** → "wancha".
- t tushib qolishi: **next day** → nex day, **last night** → las night.
- American flap t: **water** → "wader", **better** → "bedder".

## ⚡ Hiylalar
- Gapni bitta uzun so'zdek ayting: *Whatareyoudoing?* → /wɒtəjəˈduːɪŋ/.
- Tinglashda tushunmasangiz — muammo so'z emas, linking. Sekinlatib qayta eshiting.

## ✅ Bugungi topshiriq
- "Pick it up and put it on" — 5 marta tez.
- Bitta film parchasidan 1 gapni shadowing qiling.
